# Changesets

This repo uses Changesets for the first publishable private framework packages:

- `@dd-bot-platform/api-contract`
- `@dd-bot-platform/channel-runtime`
- `@dd-bot-platform/core`
- `@dd-bot-platform/scenario-system`

Mixed or not-yet-extracted framework slices are intentionally excluded from this workflow until their boundaries are stable enough to publish safely.
