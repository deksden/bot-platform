# Engineering Hub

This section stores framework-owned engineering standards.

## Current docs

- [Delivery standards](delivery-standards.md): evidence-first closure rules, environment gates, and wave-level readiness expectations.
- [Coding style](coding-style.md): shared logging, error-handling, traceability, and boundary-discipline rules.

## Scope

This section is for:
- reusable process and coding discipline that multiple repos can apply;
- evidence and verification expectations for framework and product integration work;
- boundary-safe standards that do not depend on one product's domain policy.

This section is not for:
- product-only deployment runbooks;
- product trust-policy details;
- product-specific operational checklists that cannot be generalized.
